## 💻 Sobre o Projeto

Este espaço reúne o código-fonte do meu **Portfólio Pessoal**, criado para demonstrar minha evolução como **Desenvolvendo a carreira no universo de TI e Dados**. 

O site foi planejado do zero com foco em práticas modernas de **Front-end**, alta responsividade para celulares e uma navegação fluida, conectando recrutadores e visitantes aos meus trabalhos e redes de forma simples.

---

* **🏠 Início:** Apresentação inicial rápida e convite à exploração do site.
* **👤 Sobre Mim:** Um resumo da minha formação em Gestão da TI, pós-graduação em Ciência de Dados e minha paixão pela área.
* **⚙️ Especialidades:** Domínio técnico e áreas de foco (Desenvolvimento Front-end, Análise de Dados e Python).

## ✨ Funcionalidades e Destaques

- [x] **Design Totalmente Responsivo:** Experiência otimizada para computadores, tablets e smartphones.
- [x] **Alternador de Tema (Dark / Light Mode):** Suporte completo à troca dinâmica de modo claro e escuro.
- [x] **Animações e Efeitos Visuais:** Transições suaves ao rolar a página utilizando bibliotecas leves.
- [x] **Formulário de Contato Funcional:** Canal direto para envio de mensagens via e-mail.
- [x] **Navegação Inteligente:** Menu com rolagem suave que destaca automaticamente a seção visível.
